## 0. 结论速览

| 问题 | 判定 | 关键证据 |
|---|---|---|
| **AC_AM(cap=200,p=0.25) 与 AC_AD(cap=60,p=0.10) 能否拉开** | **部分成立：开局显著、NORMAL 中局方向正确但未达门槛** | 配对差 AC_AM−AC_AD：开局 **+83.5 cp (t=2.96, n=15) 显著**；NORMAL 中局 **+53.4 cp (t=1.89, n=30) 未过 t>2**；HARD +35.2 (t=1.01, n=6)。逐局面可区分性 **SEP 10/17**（基线最好的一对 AD0>EX0 只有 4/17） |

| **叠加能否同时保住 A 的"白丢子≈0"和 C 的"可控出错率"** | **不能同时** —— 这是本卡最重要的否定结论 | 丢子率(loss>300cp)：CAP_AD 0% → **AC_AD 3.9%** → **AC_AM 9.8%** → NOI_AM 15.7%。随机分支不受 cap 约束，一旦触发就可能送子；HARD 少子形里 AC_AD/AC_AM 各有 1/6 样本因随机分支崩到 749/959 cp（纯 cap 是 1.5/1.7） |
| **能否给出可换算的 cap/p 取值区间** | **成立，且给出了可外推的线性模型** | `mean(NORMAL) = (1−p)·(20.5 + 0.205·cap) + p·225`，四个实测点全部命中（预测 52.0/102.4 vs 实测 50.5/103.9，纯 cap 两点精确复现）。换算表见 §7 |
| **cap 的语义在不同局面类型不等价** | **新发现的硬事实，接线必须处理** | cap-分支均值对 cap 的斜率：中局 0.205 cp/cp，**开局 0.467 cp/cp（2.3 倍敏感）**。同一个 cap=200 在中局给 61.5、在开局给 86.1 |

一句话结论：**叠加确实把两个方向合成了一个可调的阶梯（中局 EX0 3.9 < AD0 15.8 < CAP_AD 32.8 < AC_AD 50.5 < CAP_AM 61.5 < AC_AM 103.9），但"不白丢子"这个性质在叠加里保不住**——cap 只约束引擎分支，随机分支是完全无界的，它以 p 的概率把局面直接扔回"业余乱走"。要同时得到"不白丢子"和"会犯错"，必须把随机分支也过滤（只在劣化≤cap 的着法里随机），那是新规则，本卡未测。

## 1. 方法

### 1.1 与上一卡的关系
题集、度量、引擎、驱动配方全部沿用 t_ef6e93b8 / t_9f14af96：同一 17 局面（5 开局 + 12 中局），`loss = anchor + ref`（越低越强），Threads=4，ANCHOR/REF 都是 MultiPV=1 movetime 2000 ms Hash 256。

### 1.2 新规则 `capnoise`（alt_rules.js）
```
先按 cap 选候选（= 方案 A）：取 gap(top1−slot) ≤ cap 里最差的一个；若全部超 cap 则取槽 1（hit=above）
再以概率 p 覆盖（= 方案 C）：从 pos.legal 里均匀随机抽一步合法着法直接走（hit=rand）
```
cap 分支不消耗随机数，所以 **p=0 时逐位等价于 `cap` 规则**（单元测试已断言）。日志里 `probs` 带 `cap=/p=/legal=/各槽 gap/wouldBe=`，`wouldBe` 记录"若没被随机覆盖本会走哪个槽"，用于事后归因。

## 3. 规则行为（实测 vs 设计）

| cfg | 设计 p | 实测随机命中率 | 离线按同一 seed 复现 | hit 标记不一致 |
|---|---|---|---|---|
| AC_AD | 0.10 | 6/51 = **0.118** | 6/51 = 0.118 | **0** |
| AC_AM | 0.25 | 14/51 = **0.275** | 14/51 = 0.275 | **0** |
| NOI_AD / NOI_AM（对照） | 0.10 / 0.25 | 0.176 / 0.373 | 完全一致 | 0 |
| 10 万次合成抽样（同一 seed 构造） | 0.25 | **0.2498** | — | — |

规则本身无偏（逐条复现 0 处不一致 + 10 万次合成抽样 = 0.2498）；实测偏离是 n=51 的小样本波动（p=0.25 时该比率的 sd≈0.061，0.275 约 0.4σ）。
**接线时若要保证"每 N 步出错一次"的手感，应改用固定配额而不是独立概率**（上一卡已提出，本卡再次确认：n=51 时 realized p 的 sd 是 0.04–0.07，单轮不可控）。

cap 上限是否被遵守：**cap 分支 0 处违反**（AC_AD 45 次引擎分支 = cap 37 + above 8、AC_AM 37 次 = cap 32 + above 5，全部 gap ≤ cap；分析器 `capViolations=[]`）。
cap 在 HARD 局面仍自动退化：AC_AD 的 HARD 样本 5/6 是 `above`（gap=0，退回槽 1），AC_AM 5/6 同样——与上一卡一致，这条硬边界没有被叠加改变。
随机分支覆盖掉的槽位（`wouldBe`）：AC_AD 6 次里 5 次原本会走槽 8、AC_AM 14 次里 11 次原本会走槽 8 —— 即被覆盖的正是 cap 精心挑出来的"可接受劣化"着法。

## 5. 验收判据 1：AC_AM 与 AC_AD 是否显著拉开

- **开局组：是。** +83.5 cp，t=2.96，95%CI [+28.2, +138.9]，逐样本 12 胜 / 2 平 / 1 负。
- **NORMAL 中局：方向成立但差一步。** +53.4 cp，t=1.89，CI [−2.1, +109.0] 跨 0；逐样本 16 胜 / 6 平 / 8 负。**n=30 下这是"很可能真实、但本卡不足以判定"的状态**，不是"无效应"。
- **HARD：不可判。** n=6，且两档在这里都由"随机分支这一轮有没有触发"决定（AC_AD 的 HARD 逐轮均值 4.5 / 2.5 / 376.5）——硬边界未被叠加改变。
- **AC_AM 相对现基线 AM0：** NORMAL **显著更弱 +68.8 cp (t=3.39)**，开局相当（−0.7），HARD 显著更强（−424.8）。→ "比现基线弱档更弱"这一半只在真正有中间梯度的局面里成立；在少子形里叠加反而更强，因为 cap 挡住了送子。

**判定：部分成立。** 两档的期望差是真实的、单调的、可复现的（开局与"AC_AM vs AM0/AD0/EX0"都过门槛），但卡内指定的 cap60/p0.10 vs cap200/p0.25 这一对在中局自身的 t 值差 0.11 未达门槛。若要把这一对判到显著，需要把 NORMAL 样本翻倍（n=60 时 t≈2.7），或把 AC_AD 挪到离邻居更远的位置（例如 cap=100,p=0.05 → 预测 45 cp，与 CAP_AD 拉开）。

|---|---|---|---|---|---|---|

| **AC_AD** | 29% | 43% | 24% | 0% | **4%** | 50.9 |
| **AC_AM** | 18% | 33% | 25% | 14% | **10%** | 111.0 |
| NOI_AD | 82% | 8% | 4% | 0% | 6% | 26.7 |
| NOI_AM | 24% | 24% | 20% | 18% | 16% | 158.7 |

**结论：不能同时保住。**
1. **A 的"白丢子=0"被叠加破坏。** 全部 7 个 AC 丢子样本 **100% 来自随机分支**（AC_AD 2 例：MG_QT24 460cp、MG_QT19 749cp；AC_AM 5 例：MG_QT34 346、MG_QT39 392、MG_QT14 457、OP06 305、MG_QT19 959），cap 分支一次都没有。原因很直接：cap 只过滤引擎候选池，随机分支从 `pos.legal` 里均匀抽样，**完全无界**。
2. **C 的"会犯错"确实被保留了，而且比纯 C 温和**：出错率随 p 线性可控 —— 实测丢子率 p=0 → 0%，p=0.10 → 3.9%，p=0.25 → 9.8%（纯 C 的 p=0.25 是 15.7%）。随机分支自身的丢子率约 35%（7/20），所以期望丢子率 ≈ 0.35·p，与实测吻合。
3. **HARD 局面出现新的双峰形态**：cap 分支走完美着法（HARD gap=0），随机分支可能直接崩。AC_AD 的 HARD 逐轮均值 4.5 / 2.5 / **376.5**，AC_AM 6.0 / 0.0 / **483.0**。比纯噪声（NOI_AM 728/605/586）安全得多，但比纯 cap（4.5/0.5/−0.5）不稳定。
4. **逐局面可区分性（±20cp，17 局面）：** AC_AM > AC_AD **SEP 10 / FLAT 6 / INV 1**，AC_AM > AD0 SEP 9，AC_AM > EX0 SEP 10；对照基线最好的 AD0>EX0 **SEP 4 / FLAT 13**，纯噪声 NOI_AM>AD0 SEP 11。叠加把"每局都能感到差别"做到了接近纯噪声的水平，同时把 INV（前者反而更强）从纯噪声的 6 降到 1。

## 7. 验收判据 3：cap/p 换算表（可直接接线的部分）

### 7.1 已验证的换算模型
两条分支各自独立测量，叠加是它们的加权平均：

```
mean(NORMAL 中局) = (1−p) · capBranch(cap) + p · randBranch
其中  capBranch(cap) = 20.5 + 0.205 · cap      （实测 cap=60→32.8, cap=200→61.5，两点定线）
      randBranch     ≈ 225 cp                    （实测 AC_AD 分支 241、AC_AM 分支 225）
      期望丢子率 ≈ 0.35 · p                      （实测随机分支丢子率 7/20 = 35%）
```
模型对四个实测点的预测误差 ≤ 1.5 cp：

| 配置 | 预测 | 实测 |
|---|---|---|
| CAP_AD (cap60,p0) | 32.8 | **32.8** |
| CAP_AM (cap200,p0) | 61.5 | **61.5** |
| AC_AD (cap60,p0.10) | 52.0 | **50.5** |
| AC_AM (cap200,p0.25) | 102.4 | **103.9** |

（上一卡的粗略说法"cap 实测劣化 ≈ cap 的 26–37%"在本轮是 41% / 27% —— 更准确的是上面的线性式：截距 20.5 + 斜率 0.205。）

### 7.2 "想要 X cp 实际劣化 → 用哪个 cap/p"（NORMAL 中局口径）

| 目标劣化 | 可选取值（cap, p）→ 预测 | 备注 |
|---|---|---|
| ~30 | cap=60, p=0 | 纯 A；此时不丢子 |
| ~40 | cap=60, p=0.04 / cap=100, p=0 | |
| ~50 | **cap=60, p=0.09**（本卡 AC_AD）/ cap=150, p=0 | |
| ~60 | cap=60, p=0.14 / cap=100, p=0.10 / **cap=200, p=0** | |
| ~80 | cap=100, p=0.21 / **cap=200, p=0.11** | |
| ~100 | cap=100, p=0.32 / **cap=200, p=0.24**（≈本卡 AC_AM） | |
| ~120 | cap=200, p=0.36 / cap=300, p=0.27 | p>0.30 后随机分支主导，等于退回纯 C |

### 7.3 定标轮（p=0.15 / 0.20 插值点）——**没能判开，如实报告**

定标轮 1 轮 17 局面（357 条完整记录）：AC_P15(cap200,p0.15) NORMAL 75.2、AC_P20(cap200,p0.20) NORMAL 131.6、AC_AM(cap200,p0.25) NORMAL 136.8、AC_X1(cap60,p0.25) NORMAL 44.7。
**但每一格的随机分支只触发了 1–5 次**（n=17 时 realized p 的 sd 是 0.09–0.10，与 p 本身的间距同量级），所以这些点不能单独作为 p 阶梯的实测证据；它们只确认了方向（p↑ → NORMAL 均值↑、HARD 均值↑、丢子率 0%→5.9%→11.8%）。**定标结论要用 §7.1 的模型，而不是定标轮的逐格数字。**

### 7.4 推荐取值区间

- **可用区间：cap ∈ [60, 200]、p ∈ [0.05, 0.25]。** 低于此区间等于纯 A（不降强）；p>0.30 等于纯 C（cap 失去意义、方差失控）。
- **进阶档：cap≈60, p≈0.07–0.11（预测 46–54 cp，即本卡 AC_AD 附近）或 cap=100, p=0（预测 41）。** 注意这个窗口本身就夹在 CAP_AD(32.8) 与 CAP_AM(61.5) 之间，**步距只有 15–20 cp —— 在 n=30 下本来就判不开**（本卡 t=1.09/0.79 不是取值错，是样本量不足以分辨这么小的步距）。要造出可判的档位阶梯，要么把相邻档的预测差拉到 ≥40 cp（例如进阶 cap=60,p=0.10 ≈50 / 业余 cap=200,p=0.25 ≈103，本卡这一对就是这种间距），要么把 NORMAL 样本加倍。
- **业余档：cap≈200, p≈0.20–0.25**（预测 95–103 cp），即本卡 AC_AM 附近。
- **必须按局面类型分别定 cap**：cap-分支对 cap 的敏感度开局是中局的 2.3 倍（斜率 0.467 vs 20.5→61.5 的 0.205；开局截距 −7.3、斜率 0.467）。同一个 cap=200 在开局造成 86.1、在中局只造成 61.5；cap=60 在开局让 AC_AD(20.9) **显著强于**进阶基线 AD0(83.7, t=−2.17)。接线时要么给开局单独一套 cap，要么改用相对阈值（例如 cap 按 top1 分数跨度的一定比例）。

## 9. 与验收判据的对照（逐条）

1. **AC_AM 与 AC_AD 在 NORMAL 中局与开局是否显著拉开（t>2）** → 开局 **是**（+83.5, t=2.96）；NORMAL 中局 **+53.4 但 t=1.89，未达门槛**（方向与单调性成立，样本不足）。AC_AM 比现基线 AM0：中局显著更弱（+68.8, t=3.39）、开局相当、少子形显著更强。
2. **叠加是否同时保住 A 的白丢子≈0 与 C 的可控出错率** → **只保住后者**。丢子率 0% →(p=0.10)→ 3.9% →(p=0.25)→ 9.8%，全部来自随机分支；cap 分支 0 次越界（0 capViolations）。要两者兼得必须给随机分支加同样的上限过滤（未测，见 §10）。
3. **cap/p 推荐取值区间与换算表** → **成立**：`mean = (1−p)(20.5+0.205·cap) + p·225`，四点实测误差 ≤1.5 cp；换算表见 §7.2；推荐 cap 60–200 / p 0.05–0.25，且必须按局面类型分别定 cap。

## 10. 给下一卡的直接下一步（本卡未做）

**唯一能把"不白丢子"和"会犯错"同时拿到的改法是：把随机分支也约束。** 即 `bounded noise`：以概率 p 随机，但只在"自身 gap ≤ cap 的合法着法"（或只在候选池内非 top1 的着法）里均匀抽。本卡的证据说明这正是缺口所在——7 个 AC 丢子样本全部来自无界的随机分支，而 cap 分支一次都没有。这需要新增 1 个规则 + 单元测试 + 1 轮实测，已另开卡。
