## 基准三：最佳着法命中率（40 固定题，参考解 8000ms）

| 档位 | 命中率(新) | 命中率(基线) |
|---|---|---|
| 入门 | 12.5% | 17.5% |
| 业余 | 80.0% | 37.5% |
| 进阶 | 80.0% | 37.5% |
| 高手 | 85.0% | 92.5% |
| 大师 | 92.5% | 90.0% |

**该指标对强引擎不可靠**：混乱中局常存在多个同等好棋，越强的引擎越可能选另一条同样好的路而被判未命中（已实测到"题集按800ms筛出的错题，800ms复测命中46.7%而1800ms仅20%"的悖论）。仅对"内置引擎 vs 皮卡鱼"这种量级差有效的指标。

## 基准四：判断收敛检验（66 局面 x 800/2500/6000ms 三档评估对比）

- 800ms 与 6000ms 最终评估分歧 >=150cp 的局面：**0 / 66**
- 2500ms 与 6000ms 分歧 >=150cp 的局面：**0 / 66**

含义：皮卡鱼在 800ms（depth~16-18）时对这些中局的判断已与 6000ms 一致。这解释了基准一的和棋墙、基准二后两档饱和、基准三后两档无差异——不是测量失败，而是**后两档加深搜索在实用中局里不改变判断**。
