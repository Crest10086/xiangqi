**一句话结论**：把随机分支也套上 cap，**"不白丢子"和"HARD 不崩"两件事都拿到了，而且方差没有代价**；但代价是**强度方向反了**——bounded 随机抽的是"可接受集合"的均匀分布，而 cap 规则本身就是这个集合里最差的那个，所以加 bounded 噪声**不会比纯 cap 更弱，只会更弱于"最差"**：BN(cap=60,p=0.25) ≈ 现业余基线 AM0，要造出比 CAP_AD 更弱的档必须把 cap 提到 200。**"A 与 C 同时保住"的正确表述是：bounded noise = "A 的安全 + 把 A 的'专挑最差'换成'随机挑一个'"，它不是 C 的有界版，而是 A 的软化版。**

## 1. 方法

### 1.1 与上一卡的关系
题集、度量、引擎、驱动配方全部沿用 t_ef6e93b8 / t_9f14af96 / t_3fff5a44：同一 17 局面（5 开局 + 12 中局），`loss = anchor + ref`（越低越强），Threads=4，ANCHOR/REF 都是 MultiPV=1 movetime 2000 ms Hash 256。分组判据不变：基线 AM0 池里 gap≥500 即 HARD（MG_QT01、MG_QT19）；判据仍是**配对 t>2**。

本轮噪声底（ANCH 对照，3 轮 51 样本）：全部 mean −0.8 / sd 11.3；中局 mean −2.0 / sd 11.9；开局 mean 2.1 / sd 9.2。比上一卡的 −1.6 / 7.3 略宽，判据不变。

### 1.2 新规则 `boundednoise`（alt_rules.js）
```
cap 分支（与 cap 规则逐位相同）：取 gap(top1−slot) ≤ cap 里最差的一个；全部超 cap 则取槽 1（hit=above）
以概率 p 改走随机着法，但该着法自身的劣化必须 ≤ cap：
    只从"判定为可接受的合法着法集合"里均匀抽（hit=brand）；若该集合为空则退回 cap 选择（hit=bmiss）
```
判定方式 `gapmode` 三种（本卡实测其中两种）：

| gapmode | 判定来源 | 额外搜索 |
|---|---|---|
| `pool` | 主候选池本身就是判定器；不在池里的着法一律视为不可接受（保守） | **0** |
| `probe` | 只用一次额外的宽而浅探测搜索（MultiPV 16 / 150 ms / Hash 64）判定 | 每次触发 +1 次搜索 |
| `hybrid` | 池内候选用池判定，池外着法用探测判定（卡里建议的那种定义） | 同上 |

关键实现约束（都写进了单元测试）：
- **判定只在随机分支真要触发时才做**：`AltRules.willRandom(cfg, seed)` 与 `pick()` 用同第一个随机数，驱动据此决定是否跑探测搜索，所以"预判定"不会改变任何被选中的着法（测试断言 `willRandom` 与 `pick` 零不一致）。
- **没被判定过的着法永远不会被走**（保守拒绝），因此 brand 分支的劣化天然 ≤ cap。
- 随机分支不触发时不需要判定器（否则驱动会白跳过）；触发时缺判定器必须 `skip`，不允许悄悄退化成无界随机。
- **p=0 逐位等价于 `cap` 规则**（cap 分支不消耗随机数）。

日志新增 `pnodes/pdepth`（探测搜索成本）、`pslots`（探测池分数）、`pmoves/qmoves`（主池/探测池的着法），使 `alt_verify.js` 能离线按同一 seed 完整复现判定集合与被选着法。

## 3. 规则行为（实测 vs 设计）

### 3.1 离线复现（逐条）
`alt_verify.js` 用日志里记录的 seed + 主池着法(`pmoves`) + 判定池着法(`qmoves`) 离线重跑 `pick()`：

| cfg | 设计 p | 实测 brand 命中率 | 离线复现 | move+hit 不一致 | brand 里来自主池 / 仅判定池 |
|---|---|---|---|---|---|
| BN_AD | 0.25 | 15/51 = **0.294** | 15/51 | **0** | 13 / 2 |
| BN_AM | 0.40 | 22/51 = **0.431** | 22/51 | **0** | 15 / 7 |
| BN_P2 | 0.40 | 13/51 = **0.255** | 13/51 | **0** | 13 / 0 |
| AC_AD / AC_AM（对照） | 0.10 / 0.25 | 0.078 / 0.392 | 完全一致 | 0 | — |
| 10 万次合成抽样（同一 seed 构造） | 0.25 | **0.2497** | — | — | — |

规则本身无偏（逐条复现 0 处不一致 + 10 万次合成抽样 0.2497）。BN_P2 的 0.255 vs 设计 0.40 是 n=51 的小样本波动（该比率 sd≈0.069，约 2.1σ），不是实现错误——离线按同一 seed 复现完全一致。**结论沿用上一卡：要"每 N 步出错一次"的手感必须用固定配额，独立概率在 n=51 量级不可控。**

### 3.2 cap 上限是否被遵守（本卡的核心断言）
- **cap 分支 0 处越界**（`capViolations=[]`，三个配置都是）。
- **bounded 随机分支也 0 处越界**：brand 分支被判定劣化 `agap` 全部 ≤ cap —— BN_AD max 35（cap 60）、BN_AM max 103（cap 200）、BN_P2 max 122（cap 200）。
- 判定集合大小（`accept`）：BN_AD mean 9.13（min 1）、BN_AM mean 13.50（min 1）、BN_P2 mean 6.59（min 1）。**没有一次是空集**（`bmissShare=0`）；min=1 出现在 HARD 少子形——只有 top1 自己可接受，此时随机分支**退化为走安全着法**（这正是单元测试断言的行为）。
- `hit` 分布：BN_AD brand 15 / cap 32 / above 4；BN_AM brand 22 / cap 25 / above 4；BN_P2 brand 13 / cap 32 / above 6。`above`（全部候选超 cap → 退槽 1）占比 7.8–11.8%，与纯 cap 的退化率同量级 —— HARD 硬边界没有被改变，但**退化是安全的**（走 top1），不是崩掉。

### 3.3 两种判定实现的区别（可接线信息）
- hybrid 判定确实**扩大了可达集合**：BN_AM 的 22 次 bounded 着法里 **7 次（32%）是主池里没有、只有探测找到的**；BN_AD 15 次里 2 次。
- 但**质量上没有可测差别**：BN_AM vs BN_P2（同 cap/p，只差判定方式）配对差 NORMAL **+1.0 cp (t=0.14)**、开局 −6.3 (t=−0.33)、HARD −0.5 (t=−0.34) —— 不可区分。
- 代价差很大：见 §8。
→ **接线该用 `gapmode='pool'`（零额外搜索）；只有当希望随机分支能走到"引擎没列进 MultiPV 池"的着法时才需要探测，而那在本题集上没有换来任何强度差别。**

## 5. 为什么方向会反：机制（本卡最重要的新事实）

`cap` 规则和 bounded 随机分支面对的是**同一个可接受集合**（gap ≤ cap 的着法），但取法不同：

| | 取法 | 期望劣化（本卡实测，NORMAL+开局+HARD 合并 51 样本） |
|---|---|---|
| `cap` 规则 | 集合里 **gap 最大的那一个**（故意挑最差） | E[max accepted gap] = **26.5**（cap60）/ **55.9**（cap200） |
| bounded 随机 | 集合里 **均匀抽一个** | E[mean accepted gap] = **13.8**（cap60）/ **28.7**（cap200） |
| 实测落地劣化 | — | CAP_AD 26.3、CAP_AM 55.0；BN_AD **22.2**、BN_AM **48.5**、BN_P2 **46.0** |

即：**均匀抽的期望劣化 ≈ 挑最差的一半左右**（13.8/26.5 = 0.52，28.7/55.9 = 0.51）。所以把"以概率 p 改走随机着法"换成 bounded 之后，那一支不是"更差的分支"，而是"比 cap 更宽松的分支"——叠加它只会把整体**变强**。

配对分解（NORMAL 中局，同局面同轮）：

| | BN 走 bounded 随机着法的抽样 | BN 走自己 cap 选择的抽样 |
|---|---|---|
| BN_AD vs CAP_AD | n=8，**−43.8 cp**（更强） | n=22，−7.2 cp |
| BN_AM vs CAP_AM | n=14，**−22.5 cp**（更强） | n=16，+2.0 cp |

（同池同规则的两条 cap 分支本身应当逐位相同；实测 22 次里只有 4 次选到同一个着法，差 −8.2 cp——这是 MultiPV=8 池本身的不稳定 + 判定探测搜索污染哈希表带来的噪声（BN_AD 与 CAP_AD 的 top1 分差 mean −1.7 / sd 8.0），不是规则差异。这个 sd 8.0 与 ANCH 噪声底 sd 11.9 同量级。）

**结论表述必须改**：上一卡说"bounded noise 是把不白丢子和会犯错同时拿到的唯一路径"。实测修正为：**bounded noise 是"A 的软化版"——它把 A 的"专挑可接受集合里最差的"换成"在可接受集合里随机挑"，因此它比 A 更强、且同样不丢子；它不能替代 C 的降强作用。要降强只能加大 cap。**

## 7. 验收判据 3：bounded 版本的 cap/p 换算式

### 7.1 分支可加模型（与上卡同构，只换掉 p 项）

```
mean_BN(class, cap, p) = capBranch(class, cap) + p·(1−q)·( BND(class, cap) − capBranch(class, cap) )

capBranch(class,cap)  本卡实测两点定线：
    NORMAL  = 31.8 + 0.200·cap      （cap60→42.2, cap200→66.4）
    OPENING = −7.2 + 0.500·cap      （cap60→22.5, cap200→92.0）   ← 斜率是中局的 2.5 倍
    HARD    = −1.2 + 0.000·cap      （cap60→0.2,  cap200→3.3）    ← HARD 与 cap 无关（硬边界）

BND(class,cap)  bounded 随机分支的实测均值（不再是无界的 225）：
    NORMAL  = 7.4（cap60,hybrid） / 52.6（cap200,hybrid） / 39.8（cap200,pool）
    OPENING = −0.5 / 28.2 / 12.5
    HARD    = 5.7 / 0.0（accept 只剩 top1 → 等价于 cap 分支）

q = 判定集合为空的抽样占比。本卡 q = 0（accept 最小 1，永不为空；HARD 的退化表现为 accept=1 而非 0）
```

对照上卡的无界式 `mean = (1−p)(20.5+0.205·cap) + p·225`：**唯一被替换的就是 p 项——225 cp 变成 BND，且 BND < capBranch**，所以 bounded 叠加必然把均值往**下**拉（变强）。

### 7.2 模型对实测点的误差（`bn_model.js`）

| 配置 | 预测 | 实测 | 误差 |
|---|---|---|---|
| BN_AD (cap60,p0.25) NORMAL | 33.5 | **25.2** | +8.2 |
| BN_AM (cap200,p0.40) NORMAL | 60.9 | **57.0** | +3.9 |
| BN_P2 (cap200,p0.40,pool) NORMAL | 55.8 | **56.0** | **−0.2** |
| BN_AD HARD | 1.5 | 5.0 | −3.5 |
| BN_AM HARD | 2.0 | 3.7 | −1.7 |
| BN_P2 HARD | 3.3 | 4.2 | −0.8 |
| BN_AD OPENING | 16.8 | 18.3 | −1.5 |
| BN_AM OPENING | 66.5 | 73.6 | −7.1 |
| BN_P2 OPENING | 60.2 | 79.9 | **−19.7** |

**可用范围**：NORMAL 中局误差 ≤8 cp、HARD 误差 ≤3.5 cp、开局 hybrid 误差 ≤7 cp。
**不可外推**：开局 + pool 判定误差 19.7 cp（pool 判定在开局把大量着法判成不可接受，accept 集合被显著缩小，分支均值模型低估了退化）。开局必须用实测点，不能用式子。

### 7.3 更实用的经验式（本卡新测出的比例）

从日志里的各槽 gap 直接算"可接受集合"的形状（51 抽样，三个配置独立吻合）：

```
可接受集合大小（池内候选数）        mean 5.88（cap60） / 6.63（cap200）      ← 与 cap 几乎无关
E[ 最大可接受 gap ]（= cap 规则会走的那个）  26.5（cap60） / 55.9（cap200）   → 0.44·cap、0.28·cap（亚线性）
E[ 可接受 gap 的均值 ]（= bounded 随机分支的期望） 13.8（cap60） / 28.7（cap200） → 0.23·cap、0.14·cap
比值  E[均值]/E[最大] = 0.52 / 0.51                                             ← 稳定的那条
实测 brand 分支 judged gap      9.5（cap60） / 37.4（cap200） / 26.2（pool, cap200）
```

**可外推的那条是比值，不是斜率**：`E[bounded 分支劣化] ≈ 0.5 × E[cap 规则劣化]`（两个 cap 都是 0.51–0.52）。
**不能外推的是绝对值**：可接受集合的最大 gap 对 cap 是亚线性的（0.44→0.28），所以"把 cap 定到 目标/0.2"这种线性换算在 bounded 下不成立——必须用 §7.1 的分支式（capBranch 由两点实测定线）或直接用实测点。

### 7.4 "想要 X cp（NORMAL 中局）→ 用哪个 cap/p"（bounded 口径）

| 目标劣化 | 取值 | 依据 |
|---|---|---|
| ~18–25（≈现业余基线 AM0） | **cap=60, p=0.25, gapmode=pool** | 实测 BN_AD 25.2（hybrid）/ BN_P2 同族 56（cap200）；BN_AD 与 AM0 t=0.07 不可区分 |
| ~30–40 | cap=100, p=0.30（插值） | 介于 BN_AD(25.2) 与 CAP_AD(42.2) 之间；**注意这一段与纯 cap 重叠，判据上判不开** |
| ~45–55 | **cap=200, p=0.40, gapmode=pool**（=本卡 BN_P2） | 实测 56.0，零额外搜索 |
| ~60–70 | cap=250–300, p=0.40（外推，未测） | 式外推；CAP_AM 66.4 是上界参照 |
| 想要比 CAP_AD 更弱但又不丢子 | **必须加大 cap，不能加大 p** | BN_* 的 p 越大反而越强（p↑ → 更多抽样落到均匀分布 → 均值下降） |

**p 的作用变了**：在无界叠加里 p 是降强旋钮；在 bounded 里 p 主要是**方差/手感旋钮**（p↑ 让着法更不可预测）而**不是降强旋钮**——BN_AD→BN_AM 之所以变弱，是因为 cap 从 60 提到 200。

### 7.5 推荐取值区间（bounded）

- **可用区间：cap ∈ [60, 200]、p ∈ [0.15, 0.40]、gapmode='pool'。** p 低于 0.15 等于纯 cap（着法太可预测）；p 高于 0.40 不进一步降强，只增加不可预测性与方差（BN_AM perPosSd 18.4 vs CAP_AM 11.8）。
- **进阶档：cap≈60–100, p≈0.20–0.30**（实测/插值 25–35 cp）。
- **业余档：cap≈200, p≈0.35–0.40**（实测 56–57 cp）。
- **必须按局面类型分别定 cap**：开局斜率是中局的 2.5 倍（0.500 vs 0.200），同一个 cap=200 在开局造成 79.9、在中局只造成 56.0；cap=60 在开局让 BN_AD(18.3) **显著强于**进阶基线 AD0(80.0, t=−2.50)。

## 9. 方差与可区分性（bounded 的代价在哪）

| cfg | 轮均漂移 | 单局面 sd | 跨轮着法不稳定 | 逐局面可区分性（±20cp，17 局面） |
|---|---|---|---|---|
| CAP_AD | 10.4 | 8.4 | 11/17 | — |
| **BN_AD** | **3.5** | **9.2** | 13/17 | BN_AD>CAP_AD **FLAT 14 / INV 3 / SEP 0** |
| **BN_P2** | **4.4** | **14.4** | 15/17 | BN_P2>BN_AM SEP 3 / FLAT 11 / INV 3 |
| **BN_AM** | **15.8** | **18.4** | 15/17 | BN_AM>AM0 SEP 5 / FLAT 8 / INV 4；BN_AM>EX0 SEP 8 / FLAT 7 / INV 2 |
| AC_AD（同轮无界对照） | 30.1 | 73.9 | 12/17 | — |
| AC_AM（同轮无界对照） | 85.8 | 99.5 | 16/17 | AC_AM>AM0 SEP 11 / FLAT 3 / INV 3 |
| NOI_AM | 35.9 | 43.1 | 15/17 | — |

- **方差代价基本为零**：BN_AD 轮均漂移 3.5（比 CAP_AD 的 10.4 还低），单局面 sd 9.2 ≈ CAP_AD 8.4；相比无界叠加（AC_AM 85.8/99.5）低一个数量级。上一卡的"叠加把方差集中到最敏感处"的问题被 bounded 消除。
- **代价出现在"每局都能感到差别"**：bounded 的逐局面可区分性明显低于无界叠加（BN_AM>AM0 SEP 5 vs AC_AM>AM0 SEP 11）。因为 bounded 的单局行为太接近纯 cap，玩家在一局里察觉不到"它在乱走"。
  → 若产品要的是"这个档明显是个业余，每局都看得出来"，bounded 不如无界叠加；若产品要的是"这个档不会犯低级错误但会选次好着法、每局表现稳定"，bounded 明显更好。**这是产品取向选择，不是数值优劣。**

## 10. 与验收判据的对照（逐条）

1. **丢子率能否回到 ≈0%，同时 NORMAL 中局仍比 CAP_\* 明显更弱（配对 t>2）** → **前半成立（0/51，三个配置都是 0%）；后半不成立且方向相反**（BN_AD 比 CAP_AD 强 16.9 cp, t=−2.37）。"同时保住 A 与 C"的正确表述：保住的是 A 的全部性质 + 把 A 的"挑最差"换成"随机挑"，**不是** A 与 C 的叠加。要更弱必须加大 cap。
2. **HARD 组双峰是否消失（对照 AC_AD 逐轮 4.5/2.5/376.5）** → **成立**：BN_AD 5.5/3.0/6.5、BN_AM 6.0/2.0/3.0、BN_P2 4.5/6.0/2.0，最差轮 6.5 cp，与纯 cap / 噪声底同级。原因是 HARD 里判定集合只剩 top1，随机分支被迫走安全着法。
3. **给出 bounded 版本的 cap/p 换算式** → **成立**：`mean_BN = capBranch + p(1−q)(BND − capBranch)`，`capBranch(NORMAL)=31.8+0.200·cap`、`capBranch(OPENING)=−7.2+0.500·cap`、`capBranch(HARD)≈0`；**BND 取代无界的 225**，实测 NORMAL 7.4–52.6。NORMAL 误差 ≤8 cp、HARD ≤3.5 cp；**开局 pool 模式误差 19.7 cp，不可外推**。经验比例 `E[bounded 判定劣化] ≈ 0.16–0.19·cap`。
4. **若随机着法的劣化判断需要额外搜索成本，必须报告 nodes/步** → **已报告**：hybrid 判定 +96,868（BN_AD）/ +138,546（BN_AM）nodes/步，即 +32%~+45%；**pool 判定 0 成本且质量不可区分（t=0.14）→ 接线用 pool**。

## 11. 给接线的直接建议（本卡证据支持的）

1. **弱档规则该用 `boundednoise` + `gapmode='pool'`**：不白丢子（0%）、HARD 不崩（≤6.5 cp）、方差等于纯 cap、**零额外搜索**、实现只需一次池内过滤。
2. **强度阶梯用 cap 定，不用 p 定**：进阶 cap≈60–100（实测 25 cp 附近 = 现业余基线）、业余 cap≈200（实测 56 cp）。p 用来调"可预测性/手感"，取 0.20–0.40。
3. **开局必须单独定 cap**（斜率 2.5 倍），或改用相对阈值。
4. **若要"每 N 步明显错一次"的可感错误**，bounded 给不了（可区分性 SEP 5 vs 无界 11）；那需要固定配额 + 允许一次**无界**抽样，或把 cap 加大到能产生 150–300 cp 的劣化（仍不丢子）。这是下一卡唯一值得试的方向。
5. **cap 的"专挑最差"本身是个可选设计**：本卡发现把"挑最差"换成"在同一可接受集合里随机挑"就自动变强 **10–17 cp**（BN_AD−CAP_AD −16.9 t=−2.37；BN_P2−CAP_AM −10.4 t=−1.96，两者都是同 cap 同池、只差取法）。若产品其实想降低 CAP_* 的强度而不动 cap，改取法就够了，不需要任何随机概率——这是本卡意外的副产品，值得单独确认。
